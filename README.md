# Hotel_booking_system
Hotel Room Booking System
Application Name: Starshine Hotel 
Problem Statement: Small hotels and guest houses often use notebooks and/or unorganized spreadsheet files to book their rooms, which results in double bookings, missing information, time-consuming search of the guest’s booking, and difficulties in calculating the bill.
Target users: Hotel Receptionist/Administrator.
Goal: To allow the Receptionist to handle rooms and booking using a single menu driven application. It should avoid double booking, calculate costs automatically, and save information across sessions.
Proposed Features:
•	Add a new room (Room Number, Type of Room, Price per Night)
•	Display all available rooms with status
•	Book a room for a particular guest (Guest Name, Contact No, Number of Nights)
•	Search booking by Guest Name/Room Number
•	Check out the guest and generate total Bill with a long stay discount
•	Cancel the booking
•	Generate a small report (Occupancy and Total Income)
•	Automatic saving and loading of data from file Expected input: Menu choice, room number, room type, price, guest name, phone number, number of nights.
Expected input: Menu choice, room number, room type, price, guest name, phone number, number of nights.
Expected output: Formatted room and booking tables, confirmation messages, error messages for invalid input, a bill summary, and an occupancy and revenue report.
